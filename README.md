# KRONYX Labs — site conceptuel

Site statique responsive, prêt pour GitHub Pages. Tout le contenu est en français.

## Publication sur GitHub Pages
1. Décompressez `KRONYX-Labs.zip`.
2. Créez un dépôt GitHub et envoyez-y le contenu de ce dossier (le fichier `index.html` doit être à la racine).
3. Dans **Settings → Pages**, choisissez **Deploy from a branch**, la branche principale et le dossier **/(root)**.
4. Attendez la publication puis ouvrez l'URL indiquée par GitHub.

## Personnalisation
- Couleurs et mise en page : `assets/css/style.css`
- Menu mobile : `assets/js/main.js`
- Logos PNG : `assets/logos/`
- Illustrations vectorielles des GPU : `assets/images/`

Le nom KRONYX dans l'en-tête est du texte, pas une image. Le PNG KX est utilisé comme favicon. Les fichiers PNG fournis ici sont des variantes graphiques recréées pour cette archive ; le fichier original du favicon précédemment envoyé n'était pas accessible comme pièce jointe dans cette conversation. Remplacez `assets/logos/kronyx-favicon.png` par votre PNG original en conservant ce nom pour utiliser exactement votre dessin.

Les GPU et caractéristiques sont des concepts fictifs. KRONYX Labs n'est pas affiliée à NVIDIA ou AMD.
